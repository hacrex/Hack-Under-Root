# Open Debug Theme

`open-debug-theme.xml` is a clean-room Blogger theme for private debugging and import testing.

## What changed

- It replaces the copied debug export with a new original theme scaffold.
- It does not bundle proprietary theme code, restricted JavaScript assets, restricted template payloads, or sample posts.
- It keeps similar open functionality through original markup, CSS, and small vanilla JavaScript helpers.

## Included functionality

- Responsive header, hero, main post feed, sidebar, and footer sections.
- Blogger Blog, Profile, Label, Popular Posts, and Attribution widgets.
- SEO basics such as canonical URL, description metadata, Open Graph title, and Twitter card type.
- Optional dark mode, cookie notice, search overlay, ad placeholder, and manual link-gate helper.
- Empty-state messaging so import tests do not require bundled demo content.

## Intended use

Use this file for local/private Blogger import testing. Configure ads, analytics, menus, pages, and posts from the Blogger dashboard or Layout editor after import.
